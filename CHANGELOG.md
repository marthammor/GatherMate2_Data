# GatherMate2_Data

These are my personal updates to the GatherMate2_Data addon. You should still check for updates from the original author! All changes here except the data have been submitted to them to update the original addon and you should give them your support!

I recommend that you set the 'Import Style' to 'Merge' and set the expansion to 'The War Within' and check 'Expansion Data Only' when importing this data into your own GatherMate2 addon. These files may only contain partial data or may not contain any data at all for previous expansions. I'm not responsible for any data lost!

## What's Changed

* Updated Herbalism and Mining node locations from WoWHead for The War Within (4/20/2025).
* Updated Fishing pool nodes for The War Within.
  * Note: These are from my own gathered fishing nodes as WoWHead no longer provides locations for fishing pools.
